Commands.

Command syntax, what each command does, and the permission check found in the bot code.

Use the prefix configured for your server (default ,). Permission labels show the caller-side check in ONYX's code; Discord role hierarchy and the bot's own permissions may also affect whether an action succeeds. Commands marked Any member have no additional caller permission decorator in the inspected command definition.
